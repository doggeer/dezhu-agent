## 4. 代码含义

### core/slash_commands.py
新增模块，实现三个内置 slash 命令。核心设计是 `CommandResult` 三态枚举 —— `QUIT` 终止循环、`HANDLED` 跳过模型调用（/messages /usages /help 从此不再被当作普通消息送给 LLM）、`PASS` 正常交给模型。每个命令独立为一个下划线前缀的函数，方便单独测试。

### core/agent.py
`agent_loop()` 的主循环从简单的 quit/exit 布尔检查升级为三态分支：QUIT → break，HANDLED → continue（直接跳过 model_client.try_recover_main() 和 run_conversation()），PASS → 进入原有模型调用流程。斜杠命令不会再写入消息列表或触发模型。

### tests/test_slash_commands.py
4 个测试类，覆盖路由信号的正确性（三种枚举值）、输出格式（role / token / content 预览 / 截断）、状态判定阈值（OK / Compression needed / Near limit）以及 /help 的完整性。
